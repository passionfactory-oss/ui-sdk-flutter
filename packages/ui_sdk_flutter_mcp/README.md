# ui_sdk_flutter_mcp

An MCP server that lets coding agents read and operate a running app built with `ui_sdk_flutter` through its agent bridge. It runs as a separate process and talks to the app over the Dart VM service.

This package is a placeholder. See [ADR-0003](../../docs/adr/0003-agent-bridge-over-vm-service-and-mcp.md) for the design.
